# FlowBridge v0.4.0 发布说明

发布日期：2026-08-04  
版本主题：稳定连接

## 这次解决了什么

- 修复“一台能发、另一台收不到”：实时通知之外增加 30 秒补拉，断线、睡眠唤醒和网络切换后自动重连。
- 文件传输改为主进程持久化队列：45 MB 分片、失败自动重试、重启续传、接收端 SHA-256 完整性校验。
- 接收端错过通知后仍能发现待接收文件；设置下载目录后可以后台自动接收。
- 关闭窗口时可缩到 Windows 托盘，传输任务不会因界面关闭而中断。
- 新增程序内更新。v0.3.3 用户手动安装本版一次，后续版本可直接在“设置 → 软件更新”中更新。
- 新增头像和壁纸上传、预览、替换、恢复默认及壁纸遮罩调整。
- 新增通知中心、连接诊断、设备版本与协议兼容提示。
- 修复剪贴板清理、收藏、删除以及设备重命名、移除只在本地生效的问题。
- 移除或补齐无结果控件；`Ctrl K`、通知铃铛、传输重试和清理均连接到真实动作。

## 升级前须知

1. Supabase 项目需先执行 `supabase/migrations/202608040001_v04_reliability.sql`。
2. 两台电脑都要先手动安装 v0.4.0；版本协议过旧的设备不会继续文件传输。
3. 在每台电脑的“设置 → 下载目录”选择保存位置，并打开“自动接收文件”。
4. v0.4.0 保留原账号、云端数据和本地偏好，不需要重新注册。
