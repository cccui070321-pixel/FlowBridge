# FlowBridge v0.4.1 发布说明

发布日期：2026-08-04  
版本主题：头像与壁纸显示修复

## 修复内容

- 修复头像和壁纸上传成功、界面却不显示的问题。
- 根因是 Electron 内容安全策略阻止加载 Supabase 私有 Storage 的签名图片。
- 图片白名单只增加 `https://*.supabase.co`，没有开放任意外部图片网站。
- 修复重复选择同一张图片时不再触发上传的问题。
- 增加 Windows 图片解码备用路径，并在页面内持续显示处理、上传、成功或具体失败原因。
- 保留 v0.4.0 的连接恢复、可靠传输、后台接收和程序内更新能力。

## 升级方式

已经安装 v0.4.0 的用户打开“设置 → 软件更新 → 检查更新”，等待下载完成后点击“重启并安装”。账号、设备、历史和设置都会保留。

## 验证结果

- 7 个测试文件、21 个自动测试全部通过。
- TypeScript 类型检查与 ESLint 通过。
- Windows NSIS 安装包和差分更新元数据生成成功。

安装包：`FlowBridge-0.4.1-Setup.exe`
