# FlowBridge

> Make Multiple Computers Feel Like One.

FlowBridge 是面向 AI 创作者的跨设备工作流助手。它希望减少微信、QQ、手机和网盘中转，让同一账号下的多台电脑可以连续发送 Prompt、文本和文件，并保留设备、历史与工作上下文。

## 当前状态

- 当前公开版本：**v0.3.3**
- 当前候选版本：**v0.4.1「头像与壁纸显示修复」已构建，待程序内更新与双机验收**
- 主要平台：Windows 10/11
- 后端：Supabase Auth、Postgres、Realtime、私有 Storage
- 已完成：双机文本同步、真实文件传输、个人主页、自定义设置、云端存储、设备与用户管理、审计基础
- 当前验证重点：断网补收、睡眠/重启续传、双向自动接收、头像壁纸同步与 v0.4.1 程序内更新演练

> [!warning] 当前最重要的产品纪律
> 页面显示“成功”不等于功能已经完成。涉及传输、同步、下载、权限和存储的功能，必须在两台真实 Windows 设备上完成端到端验证。
