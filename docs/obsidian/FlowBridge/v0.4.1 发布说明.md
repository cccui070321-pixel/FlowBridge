# FlowBridge v0.4.1 发布说明

发布日期：2026-08-04  
版本主题：头像与壁纸显示修复  
当前状态：候选版，待程序内更新与安装态图片显示验收

## 用户能感受到的变化

- 已上传的头像和壁纸可以在软件里真实显示；
- 已安装 v0.4.0 的用户直接从“设置 → 软件更新”升级；
- 不需要重新登录，也不会清空设备、剪贴板或历史。

## 根因与安全边界

图片上传和数据库保存原本成功，但 Electron CSP 阻止渲染 Supabase 签名 URL。v0.4.1 只允许 `https://*.supabase.co` 图片，不允许任意外部 HTTPS 图片。

## 技术与质量结果

- 7 个测试文件、20 个自动测试通过；
- TypeScript、ESLint 与 Windows 正式构建通过；
- 已生成 NSIS 安装包、blockmap 和 `latest.yml`。

## 最终验收

- [ ] v0.4.0 在程序内发现、下载并安装 v0.4.1；
- [ ] 重新启动后版本显示 v0.4.1；
- [ ] 已有壁纸真实显示；
- [ ] 新头像和新壁纸上传后立即显示并在第二台电脑同步。
