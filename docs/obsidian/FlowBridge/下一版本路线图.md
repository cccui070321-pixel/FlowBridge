# 下一版本路线图

## 推荐版本定义

**v0.4：把“已经能跑”升级成“普通用户能稳定连接、自动恢复并在程序内更新”的版本。**

详细范围和验收门槛已经进入 [[PRD V3.0 稳定连接版]]。

## P0：稳定性与真实验收

- 建立两台 Windows 自动/半自动验收脚本；
- 覆盖中文、英文、空格、括号、超长文件名；
- 覆盖 1KB、1MB、45MB、50MB、100MB、500MB；
- 上传中断后从已有进度恢复；
- 分片失败时自动清理孤儿对象；
- 下载取消后清理临时文件；
- 校验失败时不标记完成，并提供重新接收；
- 旧失败任务重试时要求重新选择原文件。

## P0：错误体验

- 把 SDK 错误转换成中文说明；
- 错误卡片显示错误码、原因、建议动作；
- 增加“复制诊断信息”；
- 日志不记录 Token、签名 URL、正文或文件内容；
- 管理后台增加失败传输与孤儿分片巡检。

## P0：更新能力

- 软件内检查 GitHub Release、自动下载并显示进度；
- 传输结束后提供“重启并安装”；
- v0.4.0 到测试版 v0.4.1 必须完成真实程序内升级；
- v0.3.3 到 v0.4.0 是最后一次手动安装；
- 安装包增加可信代码签名决策，降低 Windows SmartScreen 阻拦。

## P0：个性化与按钮真实性

- 头像和壁纸支持上传、预览、替换与恢复默认；
- 个性化内容在同一账号的两台设备同步；
- 工作空间、铃铛、`Ctrl K`、重试和清理等控件全部实现真实动作或移除；
- 发布前完成全页面按钮清单，确保无效按钮为 0。

## P1：工作流连续性

- Prompt 与文件建立关联；
- 最近任务/轻量项目真正云端化；
- 从某次生成结果回到对应 Prompt；
- 支持收藏、备注、标签和版本关系；
- 首页显示真实的“继续上次工作”。

## P1：本地直连

- 同局域网优先点对点传输，云端作为回退；
- 评估 WebRTC、局域网发现与 NAT 场景；
- 保持账号授权、目标确认和校验机制；
- 不因追求速度牺牲权限与可诊断性。

## P2：后续商业与生态

- 团队空间和共享权限；
- macOS 客户端；
- AI 自动分类与每日工作摘要；
- 第三方 AI 工具集成；
- 端到端加密工作空间；
- 订阅、配额与计费。

## 下一次开发前必须确认

- [ ] v0.3.3 中文小文件真实上传成功
- [ ] v0.3.3 100MB 文件真实发送与接收成功
- [ ] 两台电脑都使用同一最新版
- [ ] 普通用户/管理员越权测试结果
- [x] 自动更新采用官方 GitHub Release
- [ ] 局域网直连是否进入 v0.4，还是延后到 v0.5
