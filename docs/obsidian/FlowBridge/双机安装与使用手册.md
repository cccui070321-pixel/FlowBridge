# 双机安装与使用手册

## 安装

1. 在两台 Windows 电脑下载同一个最新安装包；
2. 关闭旧版 FlowBridge；
3. 直接覆盖安装；
4. 打开后检查左上角版本号一致；
5. 两台电脑使用同一邮箱账号登录；
6. 给两台电脑设置不同且容易识别的设备名。

## 文本发送

1. 在发送电脑选择另一台在线设备；
2. 输入或粘贴文本；
3. 点击发送；
4. 在接收电脑的剪贴板页面查看；
5. 如果开启“自动写入系统剪贴板”，可直接粘贴。

## 文件发送

1. 确认两台电脑都在线；
2. 发送端进入“文件传输”；
3. 选择目标设备；
4. 点击“选择文件”或拖入文件；
5. 等待状态变成“等待接收”；
6. 接收端点击“接收”并选择保存位置；
7. 完成后确认 SHA-256 校验通过。

## 大文件说明

- 单文件产品上限 500MB；
- 超过 45MB 会在后台自动拆分；
- 用户不需要手工压缩或合并；
- 接收端必须使用 v0.3.2 或更高版本；
- 建议两台设备都保持电源与网络稳定。

## 中文文件名说明

- v0.3.3 起支持中文、空格和括号文件名；
- 云端内部会使用安全英文对象名；
- 接收后的文件仍使用原始中文名。

## 排错顺序

1. 检查两台电脑版本是否一致；
2. 检查目标设备是否在线且不是当前设备；
3. 不要使用旧失败记录的重试按钮，重新选择原文件；
4. 先用小于 1MB 的 JPG 验证基本链路；
5. 再测试 2MB 视频；
6. 最后测试 100MB 大文件；
7. 记录完整错误码、文件大小、文件名和时间。
