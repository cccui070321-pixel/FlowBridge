# 发布与升级记录

## V0.1 / 初始 MVP

- 建立 Electron + React 桌面应用；
- 完成工作台、剪贴板、文件传输、Prompt Library、设备与设置界面；
- 上传 GitHub；
- 主要问题：界面可演示，但真实双机链路未完成。

## v0.2.0 — 真实双机文本同步

- 接入 Supabase Auth、数据库、Realtime；
- 同一账号下的两台设备可以在线识别；
- 文本可在两台 Windows 设备间发送；
- GitHub 功能分支保留并发布公开版本。

## v0.3.0 — 产品化升级

- 苹果式简洁浅色布局与更大字号；
- 首页、个人主页、自定义设置；
- 云端存储、配额和生命周期；
- 用户、角色、设备、配额和审计管理后台；
- 真实文件传输基础链路；
- V0.3 数据库迁移。

## v0.3.1 — 修复文件哈希 CSP

- 修复 `hash-wasm` 被 Electron CSP 拦截；
- 精确开放 `wasm-unsafe-eval`；
- 7 项测试、类型检查、Lint 与 Windows 打包通过。

## v0.3.2 — 大文件自动分片

- 适配 Supabase Free 单对象 50MB 上限；
- 超过 45MB 自动拆分；
- 接收端自动合并并校验；
- 9 项自动化测试通过。

## v0.3.3 — 中文文件名安全路径

- 修复中文、空格、括号等文件名导致 `400 Invalid key`；
- 云端 key 与原始文件名分离；
- 增加截图中 JPG、DOCX、MP4 文件名回归测试；
- 10 项自动化测试通过；
- 提交：`aad361a`。

## v0.4.0 — 稳定连接（候选版）

- Realtime 状态机、指数退避重连、20 秒心跳和 30 秒补拉对账；
- Electron 主进程持久化传输队列，45MB 分片上传/下载、自动重试、重启续传和 SHA-256 校验；
- 后台托盘与自动接收，程序恢复和 Windows 唤醒后主动修复连接；
- GitHub Release 稳定通道程序内更新；
- 头像、壁纸、通知中心、连接诊断和设备协议兼容提示；
- 剪贴板、设备和传输清理按钮连接真实云端动作；
- V0.4 Supabase 迁移已于 2026-08-04 执行成功；
- 7 个测试文件、19 个自动测试、TypeScript、ESLint、正式构建与 npm 0 漏洞审计通过；
- 安装态验收发现并修复 `electron-updater` CommonJS/ESM 导入崩溃；
- 状态：安装包已生成，待两台真实 Windows 电脑与 v0.4.1 更新演练通过后发布。

## v0.4.1 — 头像与壁纸显示修复（候选版）

- 安装态复测发现头像和壁纸已上传、路径已保存，但 Electron CSP 的 `img-src` 禁止加载 Supabase 签名图片；
- 仅把 `https://*.supabase.co` 加入图片来源白名单，不开放任意外部图片域名；
- 新增 CSP 回归测试，确保私有头像与壁纸能够显示，同时不扩大为任意 HTTPS 图片；
- 7 个测试文件、20 个自动测试、TypeScript、ESLint 与 Windows 正式构建通过；
- 生成 `FlowBridge-0.4.1-Setup.exe`、blockmap 和 `latest.yml`，用于 v0.4.0 → v0.4.1 程序内升级演练；
- 状态：待发布 GitHub Release 并完成真实程序内更新。

## 安装与覆盖升级原则

- 两台电脑都应安装同一个最新版本；
- 安装前完全关闭 FlowBridge；
- 直接覆盖安装，无需卸载；
- 账号、本地设置和云端数据保留；
- 只有数据模型升级时才执行 SQL，纯客户端补丁不重复迁移。
