# FlowBridge v0.4.0 发布说明

发布日期：2026-08-04  
版本主题：稳定连接  
当前状态：候选版，待双机与程序内更新演练后公开发布

## 用户能感受到的变化

- 断线、切换网络、睡眠唤醒后会自动重连，错过实时通知仍会补收。
- 文件使用持久化分片队列，失败自动重试，软件重启后继续，完成后校验 SHA-256。
- 设置下载目录后可以后台自动接收；关闭窗口可缩到托盘继续工作。
- 头像和壁纸可上传、替换、预览和恢复默认，并同步到同一账号的设备。
- 新增通知中心和连接诊断，错误会说明原因和下一步。
- v0.4.0 是最后一次需要手动安装的过渡版，后续稳定版从程序内更新。

## 技术与质量结果

- V0.4 Supabase 迁移已执行成功。
- 7 个测试文件、18 个自动测试通过。
- TypeScript、ESLint、正式构建通过。
- npm 安全审计为 0 个已知漏洞。
- 安装态验收发现并修复 `electron-updater` CommonJS/ESM 导入崩溃。

## 发布前仍需完成

- 两台真实 Windows 设备双向传输 JPG、DOCX、MP4、100MB+ 文件；
- 断网、睡眠、退出重启和接收端离线补收；
- 两台设备头像和壁纸同步；
- 建立测试 Release，完成 v0.4.0 → v0.4.1 程序内更新。
